# Tunniplaan

Сайт расписания: администратор загружает PDF-выгрузку «Tunniplaan» из системы Tallinna
Tehnoloogiakolledž, сайт разбирает её на сервере и показывает неделю календарной сеткой.
Посетители переключают недели выпадающим списком.

- Публичная страница: `/`
- Админка: `/admin`

## Как это работает

| Слой | Что делает |
|---|---|
| `lib/parsePdf.js` | Разбирает PDF: строки восстанавливаются по координате Y, колонки — по X из шапки таблицы. Подряд идущие уроки одного предмета (перемена ≤15 мин) склеиваются в один блок. |
| `lib/store.js` | Хранилище недель. Драйвер выбирается по переменным окружения: Supabase → Vercel Blob → локальная папка `.data/`. |
| `lib/auth.js` | Один админ, пароль из `ADMIN_PASSWORD`, сессия — кука с HMAC-подписью. |
| `lib/colors.js` | Цвет предмета: слот в палитре по хэшу названия (цвет держится между неделями), внутри недели коллизии разводятся. Светлота подбирается под контраст ≥5:1 с белым текстом. |
| `components/Timetable.jsx` | FullCalendar `timeGridWeek`, на узком экране — `listWeek`. |

### Проверки при загрузке

Файл отклоняется с понятным сообщением, если: он не PDF (проверяются и MIME-тип, и
сигнатура `%PDF-`), пустой, больше 5 МБ, в нём нет строки `Tunniplaan: дд.мм.гггг - дд.мм.гггг`,
нет строки `Õpperühm:` или не распознан ни один урок. Если такая неделя для этой группы уже
загружена — приходит предупреждение с предложением заменить.

## Локальный запуск

```bash
npm install
echo ADMIN_PASSWORD=любой-пароль > .env.local
npm run dev
```

Открыть http://localhost:3210. Без ключей Supabase недели пишутся в папку `.data/` — она в
`.gitignore`, для разработки этого достаточно.

## Деплой на Vercel + Supabase

1. **Supabase**: создать проект → SQL Editor → выполнить содержимое [`supabase.sql`](supabase.sql).
   В Project Settings → API взять `Project URL` и ключ `service_role`.
2. **Vercel**: импортировать репозиторий (Next.js определяется сам, настройки менять не нужно).
3. В Vercel → Settings → Environment Variables добавить:

   | Переменная | Значение |
   |---|---|
   | `ADMIN_PASSWORD` | пароль для входа в `/admin` |
   | `ADMIN_SECRET` | любая длинная случайная строка (подпись куки; необязательно) |
   | `SUPABASE_URL` | Project URL из Supabase |
   | `SUPABASE_SERVICE_ROLE_KEY` | ключ `service_role` |

4. Deploy. Зайти на `/admin`, ввести пароль, загрузить PDF.

Ключ `service_role` даёт полный доступ к базе, поэтому он используется только в серверном
коде (route handlers и серверные компоненты) и никогда не попадает в браузер — в переменных
нет префикса `NEXT_PUBLIC_`.

### Вариант без Supabase

Если проще обойтись хранилищем Vercel: в проекте Vercel создать Blob store, переменная
`BLOB_READ_WRITE_TOKEN` подставится сама. Драйвер переключится на Blob автоматически, менять
код не нужно.
