# Tunniplaan

Сайт расписания группы TARpv24 (Tallinna Tehnoloogiakolledž). Расписание тянется прямо из
Tahvel, а недели, которых там нет, — из EduPage школы: раз в сутки само, кнопкой в админке по
требованию. Неделя показывается календарной сеткой, посетители переключают недели выпадающим
списком. PDF-выгрузку по-прежнему можно загрузить руками — как последний запасной путь.

Сдавшие экзамен по эстонскому убирают `Eesti keel teise keelena B2` галочкой над сеткой —
предмет исчезает и со страницы, и из ленты календаря; выбор помнится в браузере.

- Публичная страница: `/`
- Админка: `/admin`
- Календарь для подписки: `/tunniplaan.ics`

## Как это работает

| Слой | Что делает |
|---|---|
| `lib/tahvel.js` | Клиент публичного API Tahvel: события недели → та же структура, что даёт разбор PDF. |
| `lib/edupage.js` | Клиент публичного расписания EduPage (aSc Timetables): карточки расписания → та же структура. |
| `lib/sync.js` | Синхронизация: источники перебираются по очереди, неделя сохраняется, только если она непустая и в ней что-то изменилось. |
| `lib/lessons.js` | Общее для всех источников: даты, склейка подряд идущих уроков, чистка кодов корпуса. |
| `lib/parsePdf.js` | Разбирает PDF: строки восстанавливаются по координате Y, колонки — по X из шапки таблицы. Подряд идущие уроки одного предмета (перемена ≤15 мин) склеиваются в один блок. |
| `lib/store.js` | Хранилище недель. Драйвер выбирается по переменным окружения: Supabase → Vercel Blob → локальная папка `.data/`. |
| `lib/auth.js` | Один админ, пароль из `ADMIN_PASSWORD`, сессия — кука с HMAC-подписью. |
| `lib/ical.js` | Лента iCalendar: блок расписания → `VEVENT`, время в `Europe/Tallinn` с собственным `VTIMEZONE`. |
| `lib/colors.js` | Цвет предмета: цвета недели раскладываются по кругу равномерно, расстояние считается по перцептивной шкале и светлоте — двух зелёных в одной неделе не бывает. Светлота подбирается под контраст ≥5:1 с белым текстом. |
| `lib/optional.js` | Предметы, на которые ходит не вся группа (Eesti keel teise keelena B2). Общий список для страницы и для ленты календаря. |
| `components/Timetable.jsx` | FullCalendar `timeGridWeek`, на узком экране — `listWeek`. Под сеткой — карточки предметов с часами и днями недели (`E T K N R`). |
| `components/WeekView.jsx` | Страница недели: галочка «хожу на» скрывает необязательный предмет сразу везде — в счётчиках, сетке, легенде и адресе ленты. |

## Откуда берётся расписание

Источника два, и они перебираются по очереди: к следующему переходим, только если предыдущий не
дал за неделю ни одного занятия (или вовсе не ответил). Порядок задаётся `SCHEDULE_SOURCES`.

### 1. Tahvel

Отдаёт события расписания без авторизации:

```
GET /hois_back/timetableevents/timetableSearch?schoolId=24&studentGroups=<uuid>&from=…&thru=…
```

Из ответа собираются те же поля, что раньше вытаскивались из PDF, — на неделе 31.08–06.09.2026
результат совпал с разбором PDF байт в байт.

### 2. EduPage

Tahvel показывает расписание не всегда: группы неделями висят пустыми. Школа при этом публикует
тот же график на своей странице EduPage, и её просмотрщик ходит за данными двумя открытыми
запросами — их и повторяем:

```
POST /timetable/server/ttviewer.js?__func=getTTViewerData    → список опубликованных расписаний
POST /timetable/server/regulartt.js?__func=regularttGetData  → одно расписание целиком
```

Второй ответ — «база» aSc Timetables: справочники (`classes`, `subjects`, `teachers`,
`classrooms`, `groups`) плюс `lessons` (что за занятие) и `cards` (в какой день и урочный час оно
стоит). Карточка раскладывается по маске дней `100000`, `durationperiods` считает подряд идущие
урочные часы — так что конец сдвоенного урока берётся из последнего часа, а не «начало плюс 45
минут». Дальше — та же склейка блоков, что и у Tahvel: на неделе 31.08–06.09.2026 обе выдачи
совпали по времени, кабинетам, группам и числу уроков.

Разница одна: EduPage публикует только фамилии преподавателей, Tahvel — имя и фамилию. Поэтому
неделя, уже полученная из Tahvel, не переписывается данными EduPage, если расписание в ней не
изменилось, — иначе одна осечка Tahvel меняла бы «Terje Maarand» на «Maarand».

| Что | Куда попадает |
|---|---|
| `POST /api/sync` | Кнопка «Синхронизировать» в админке: текущая неделя и несколько следующих. |
| `GET /api/cron/sync` | Суточный крон (`vercel.json`), горизонт — `TAHVEL_WEEKS_AHEAD` недель. |

Неделя перезаписывается, только если расписание реально изменилось: пустые недели (каникулы,
ещё не опубликованный график) не сохраняются и не стирают уже показанную неделю. Названия
учебной программы нет ни у одного источника — оно подхватывается из ранее загруженного PDF,
если он был.

## Подписка в календаре (iCal)

Расписание отдаётся лентой iCalendar — её можно подключить в телефон или любой календарь,
и он будет сам подтягивать изменения после каждой синхронизации:

```
https://<сайт>/tunniplaan.ics
```

- **iPhone / iPad / macOS, Outlook** — ссылка «Подписаться в календаре» в подвале сайта
  (открывается как `webcal://`, календарь сразу предлагает подписаться).
- **Google Calendar** — кнопка «копировать ссылку» рядом с ней, дальше «Другие календари» →
  «Подписаться по URL». Google обновляет такие ленты сам, но не быстро — обычно раз в сутки.

Один блок расписания = одно событие: название предмета в заголовке, кабинет в месте, в описании
преподаватель, группы, примечание и число уроков. Время локальное таллиннское — в ленту вшит
`VTIMEZONE`, так что переводы часов не сдвигают пары.

| Параметр | Что делает |
|---|---|
| `?group=TARpv24` | только одна группа (нужен, если в базе лежат недели нескольких групп) |
| `?past=2` | не отдавать недели старше двух прошедших; по умолчанию отдаются все сохранённые |
| `?hide=eesti-b2` | без предметов, на которые студент не ходит; ссылку с этим параметром сайт подставляет сам, когда галочка снята |

Лента открыта без пароля — как и сама страница расписания. Если недель ещё нет, эндпоинт всё
равно отвечает пустым, но корректным календарём, чтобы подписка не отваливалась.

### Проверки при загрузке PDF

Файл отклоняется с понятным сообщением, если: он не PDF (проверяются и MIME-тип, и
сигнатура `%PDF-`), пустой, больше 5 МБ, в нём нет строки `Tunniplaan: дд.мм.гггг - дд.мм.гггг`,
нет строки `Õpperühm:` или не распознан ни один урок. Если такая неделя для этой группы уже
загружена — приходит предупреждение с предложением заменить.

## Локальный запуск

```bash
npm install
echo ADMIN_PASSWORD=любой-пароль > .env.local
npm run dev
```

Открыть http://localhost:3210. Без ключей Supabase недели пишутся в папку `.data/` — она в
`.gitignore`, для разработки этого достаточно.

## Деплой на Vercel + Supabase

1. **Supabase**: создать проект → SQL Editor → выполнить содержимое [`supabase.sql`](supabase.sql).
   В Project Settings → API взять `Project URL` и ключ `service_role`.
2. **Vercel**: импортировать репозиторий (Next.js определяется сам, настройки менять не нужно).
3. В Vercel → Settings → Environment Variables добавить:

   | Переменная | Значение |
   |---|---|
   | `ADMIN_PASSWORD` | пароль для входа в `/admin` |
   | `ADMIN_SECRET` | любая длинная случайная строка (подпись куки; необязательно) |
   | `SUPABASE_URL` | Project URL из Supabase |
   | `SUPABASE_SERVICE_ROLE_KEY` | ключ `service_role` |
   | `CRON_SECRET` | любая длинная случайная строка; Vercel сам шлёт её крону в заголовке |

4. Deploy. Зайти на `/admin`, ввести пароль, нажать «Синхронизировать».

Крон из [`vercel.json`](vercel.json) вызывает `/api/cron/sync` каждый день в 03:00 UTC. Без
`CRON_SECRET` этот эндпоинт открыт только администратору по куке, так что снаружи его не дёрнуть.

### Другая группа

По умолчанию сайт ведёт TARpv24. Для другой группы достаточно переменной `TAHVEL_GROUP` с её
кодом: uuid найдётся сам — по расписанию ближайших трёх недель. Если группа редкая (занятий в
этом окне нет), uuid можно задать явно через `TAHVEL_GROUP_UUID`, взяв его из адресной строки
Tahvel. В EduPage группа ищется по тому же коду, отдельной настройки не нужно.

### Другая школа в EduPage

`EDUPAGE_SCHOOL` — поддомен школы (по умолчанию `mustamae-techno`, то есть
`https://mustamae-techno.edupage.org`). Полный адрес можно задать и целиком через
`EDUPAGE_BASE_URL`.

### Порядок источников

`SCHEDULE_SOURCES=tahvel,edupage` — порядок перебора; список можно сузить до одного источника
или поменять местами. Значение по умолчанию — то же самое.

Ключ `service_role` даёт полный доступ к базе, поэтому он используется только в серверном
коде (route handlers и серверные компоненты) и никогда не попадает в браузер — в переменных
нет префикса `NEXT_PUBLIC_`.

### Вариант без Supabase

Если проще обойтись хранилищем Vercel: в проекте Vercel создать Blob store, переменная
`BLOB_READ_WRITE_TOKEN` подставится сама. Драйвер переключится на Blob автоматически, менять
код не нужно.
